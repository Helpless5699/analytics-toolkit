# 数据分析显著性检验工具箱

一个纯前端的显著性检验小工具，方便数据分析师快速完成常见指标（如留存率、转化率、均值类指标）的显著性判断。粘贴 Excel/Google Sheets 表格即可使用，所有计算均在浏览器本地完成，不会上传数据。

## 功能概览

- **比例类指标检验**：支持多天留存率、转化率等指标聚合后执行两样本比例 z 检验，自动忽略缺少数据的行（如不满对应天数的用户）。
- **数值型指标检验**：对均值类指标执行 Welch t 检验，适用于不同方差场景。
- **指标类型识别**：每个指标可独立设置为“人数/事件次数”或“比例/百分比”，也可使用自动识别。

## 使用步骤

1. 打开 `index.html`（直接双击或使用任意静态服务器）。
2. 在“粘贴数据”区域粘贴包含表头的表格数据（支持制表符、逗号、分号）。
3. 在“列映射”中选择实验分组列与样本量列。
4. 在“比例类指标检验”中选择需要聚合的留存/转化指标，并设置数值类型与显著性水平。
5. 点击“计算比例检验”获取各指标的聚合率、差值、z 值与 p 值。
6. 若需要评估均值类指标，在“数值型指标检验”中选择列后点击“计算 t 检验”。

## 本地开发

本项目不依赖任何构建工具，仅包含静态资源。如果希望通过本地服务器访问，可在项目根目录执行：

```bash
python -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000> 即可。

## 示例数据

```
cohort\tgroup\tinstalls\td1_retained\td2_retained\td1_revenue
2024-01-01\tA\t1200\t340\t210\t5.2
2024-01-01\tB\t1180\t365\t240\t5.6
2024-01-02\tA\t980\t270\t180\t4.9
2024-01-02\tB\t1020\t300\t195\t5.1
```

- 将 `installs` 作为样本量列，可对 `d1_retained`、`d2_retained` 执行比例检验。
- `d1_revenue` 可用于 Welch t 检验判断均值差异。
